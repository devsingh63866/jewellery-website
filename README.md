# Jewellery Website 💍

A **pixel-perfect, responsive jewellery eCommerce homepage** built using **HTML, CSS, and JavaScript**, designed to closely match a provided PDF design and deployed as a live static site.

---

## ✨ Features

* Pixel-perfect UI converted from PDF design
* Mobile-first and fully responsive layout
* Clean and semantic HTML5 structure
* Modern CSS3 (Flexbox, Grid, Media Queries)
* Smooth hover effects and transitions
* Optimized images and layout for performance
* Deployed as a static site on Render

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & responsiveness
* **JavaScript** – Basic interactivity
* **Git & GitHub** – Version control
* **Render** – Deployment

---

## 📱 Responsive Design

* Mobile-first approach (375px baseline)
* Tablet and Desktop breakpoints
* Tested using Chrome DevTools

## 🚀 Deployment

The project is deployed on **Render** as a static site using GitHub integration.

**Deployment steps:**

1. Push code to GitHub
2. Create a Static Site on Render
3. Set publish directory to `.`
4. Auto-deploy on every push
